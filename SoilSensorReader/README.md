# קורא חיישן קרקע 7-in-1 (Android)

אפליקציית אנדרואיד (Kotlin) שמתחברת לחיישן קרקע 7-in-1 (לחות, טמפרטורה,
EC, pH, NPK) דרך USB ומציגה את הנתונים בזמן אמת.

## איך זה עובד

החיישן שלך מוציא USB עם ממיר USB-to-Serial פנימי (לרוב שבב CH340).
האפליקציה:

1. מזהה את החיישן דרך הספרייה [usb-serial-for-android](https://github.com/mik3y/usb-serial-for-android),
   שתומכת אוטומטית ב-CH340 / CP210x / FTDI / PL2303 / CDC-ACM.
2. פותחת חיבור serial ב-9600 baud, 8N1.
3. שולחת כל 2 שניות בקשת **Modbus RTU** (Read Holding Registers, function
   code 0x03) לכתובת slave 1, לקרוא 7 רגיסטרים החל מכתובת 0x0000.
4. מפענחת את התגובה לפי מפת הרגיסטרים הנפוצה בחיישנים מהסוג הזה:

   | רגיסטר | פרמטר       | יחידה גולמית -> תצוגה |
   |--------|-------------|------------------------|
   | 0      | לחות        | raw/10 = %RH           |
   | 1      | טמפרטורה    | raw/10 = °C (signed)   |
   | 2      | EC          | raw = µS/cm            |
   | 3      | pH          | raw/10 = pH             |
   | 4      | חנקן (N)    | raw = mg/kg            |
   | 5      | זרחן (P)    | raw = mg/kg            |
   | 6      | אשלגן (K)   | raw = mg/kg            |

**חשוב:** זו מפת הרגיסטרים והפרוטוקול הסטנדרטיים שמשמשים ברוב חיישני
ה-NPK/pH/EC 7-in-1 הסיניים מהסוג הזה - אבל בלי תיעוד רשמי מהיצרן של
החיישן הספציפי שלך, יש סיכוי שהוא שונה מעט (כתובת slave אחרת, סדר
רגיסטרים שונה, baud rate שונה כמו 4800). אם באפליקציה תראה נתונים
שגויים/הזויים (למשל pH של 3000) - כנראה שצריך לכוונן את הפרמטרים.

## איך לכוונן אם הנתונים לא נכונים

1. **קל ביותר:** פתח את `UsbSerialHelper.kt` ונסה baud rate אחר (למשל
   4800 או 19200) בפרמטר `baudRate` שמועבר מ-`MainActivity.kt`.
2. אם עדיין לא עובד, אפשר להשוות ישירות מול אפליקציית היצרן: הפעל את
   אפליקציית היצרן עם "USB debugging" מופעל ותפוס לוג של הבייטים
   שנשלחים/מתקבלים (usbmon על מחשב לינוקס עם הטלפון מחובר, או כל כלי USB
   sniffer אחר) - כך אפשר לראות בדיוק איזו פקודה האפליקציה שלהם שולחת
   ואיזה בייטים חוזרים, ולעדכן את `ModbusRtu.kt` ו-`SoilSensorReading.kt`
   בהתאם.
3. אם החיישן מגיב לכתובת slave שונה מ-1, שנה את `slaveAddress` ב-
   `MainActivity.kt`.

## פתיחה בפרויקט

1. פתח את התיקייה הזו ב-Android Studio ("Open an existing project").
2. תן ל-Gradle Sync לרוץ (יוריד את התלות `usb-serial-for-android` מ-
   JitPack וייצור wrapper אם צריך).
3. חבר את הטלפון, הפעל את האפליקציה, לחץ "התחבר לחיישן" (או פשוט חבר
   את החיישן ל-USB - האפליקציה מוגדרת לזהות אוטומטית חיבור USB חדש
   ולנסות להתחבר).
4. באנדרואיד תופיע בקשת הרשאת USB בפעם הראשונה - יש לאשר.

## מבנה הפרויקט

- `ModbusRtu.kt` - בניית בקשות Modbus RTU, חישוב CRC16, פענוח תגובות.
- `SoilSensorReading.kt` - מודל הנתונים + המרת רגיסטרים גולמיים לערכים.
- `UsbSerialHelper.kt` - ניהול חיבור USB, הרשאות, ולולאת polling.
- `MainActivity.kt` - מסך ראשי שמציג את הנתונים.
